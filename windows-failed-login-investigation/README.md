# SOC Incident Investigation Report

## 1. Incident Information

- **Incident Title:** Multiple Failed Login Attempts
- **Incident ID:** SOC-001
- **Severity:** Low
- **Status:** Investigated – No malicious activity confirmed
- **Investigator:** SOC Analyst (L1)
- **Affected Account:** mohamezo
- **Event ID:** 4625 – Failed Logon
- **Detection Tool:** Windows Event Viewer

## 2. Executive Summary

Four failed login attempts were detected on a Windows machine.

The events were generated intentionally by the user during an authorized security testing exercise.

The investigation focused on identifying the affected account, reviewing Windows Security logs, and examining the authentication failure details.

Based on the available evidence, the activity is consistent with authorized testing rather than a confirmed security incident.

## 4. Investigation Process

1. Opened Windows Event Viewer.
2. Navigated to Windows Logs → Security.
3. Searched for Event ID 4625.
4. Identified four failed login events.
5. Identified the targeted username as mohamezo.
6. Began reviewing the event details to determine the logon type and authentication failure reason.

## 5. MITRE ATT&CK Mapping

- **Tactic:** Credential Access
- **Technique:** T1110 – Brute Force

Note: This is a relevant detection category, not proof that a brute-force attack occurred.

## 6. Findings

Four failed authentication events were identified.

The activity was intentionally generated by the investigator during a controlled lab exercise.

No evidence of unauthorized access has been established from the information currently collected.

## 7. Recommended Actions

- Review the Logon Type.
- Examine the source IP address.
- Analyze Status and SubStatus codes.
- Correlate events using their timestamps.
- Monitor for additional failed login attempts.
- Investigate successful logins following repeated failures.

## 8. Conclusion

The investigation successfully detected and documented four failed Windows authentication attempts.

This exercise demonstrated the use of Windows Event Viewer to identify suspicious authentication activity and collect evidence for SOC investigation.

**Final Assessment:** Authorized lab activity. No confirmed compromise.
